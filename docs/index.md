# ADIK: SDK code and implementation knowledge together

A tool/library developer calls ADIK to build an adik. Generation creates the SDK
itself plus matching skills, contracts, examples, and implementation context. The
complete bundle travels to the consumer, whose agent uses it to implement capabilities
in application code.

Start with the [producer quickstart](getting-started/quickstart-guide.md) or
[consumer guide](getting-started/consumer-guide.md). The
[architecture walkthrough](specification/architecture.md) explains the handoff, and
the [reference adik](examples/reference-adik.md) makes it runnable.

the complete deliverable is SDK code plus the agentic elements supporting implementation.
