# ADIK explanation for sharing

ADIK helps tool and library developers generate SDKs for agents. A developer invokes
the skill suite through their coding agent; it generates SDK code plus matching
implementation skills, contracts, examples, and context as one adik.

A user then asks their own agent to implement that adik in application code. The
agent arrives with library knowledge and can focus on the application's integration
points. SDK code and implementation knowledge travel together.

The host agent executes the work. ADIK supplies the thesis, skills, and artifact
contracts. See the [architecture](../specification/architecture.md) and
[reference adik](../examples/reference-adik.md).
