# ADIK Roadmap

## 2.0.0 — Completed-adik handoff (proposed)

- Explicit producer generation and consumer implementation workflows.
- Actual SDK code and matching agentic elements in one versioned bundle.
- Native producer skills and library-specific consumer-skill requirements.
- Shared registry validation, manifest schemas, deterministic packaging.
- Package-specific registration, guarded context, and ownership-based removal.
- Runnable Python reference adik and deterministic consumer fixture.
- Updated standard, guides, architecture diagrams, migration, and evaluation protocol.

## Next evidence to collect

Run the fresh-agent consumer evaluation on representative real libraries and
applications. Record correctness, references read, unnecessary source exploration,
and corrections required. Test native discovery in the supported clients and their
current versions. The included fixtures do not claim these live-client results.

## Candidate extensions

- Additional reference adiks for TypeScript, C#, and explicitly supported frameworks.
- Migration recipes generated from version-to-version SDK changes.
- Multiple client registrations for the same installed bundle.
- Optional stronger semantic validation of cross-language types and behaviors.
- Distribution adapters and producer refresh integrations selected by developers.

Prioritize evidence that the packaged SDK and skills make implementation reliable.
